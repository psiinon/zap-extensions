Multi-Step Authentication

TOTP Step Configuration

Configures the optional 4th login step of the multi-step login, the current configuration is returned as JSON (a GET of config just returns it).

The configuration is only changed if Confirm is changed from no to yes, so that crawlers submitting the form with its default values do not change it.
